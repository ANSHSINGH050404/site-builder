# site-builder

AI-assisted site builder for generating and publishing web pages.

## Stack

Turborepo, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/site-builder.git
cd site-builder
bun install
bun run dev   # or: bun run start
```
